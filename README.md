Your computer needs specific hardware to run the AI features of the game. Verify your system meets these standards before you start:

## 🎮 How to Play

ClawTrap tasks the player with escaping a maze. You interact with the environment using your keyboard and mouse. The AI agent observes your inputs to change the maze layout and audio cues.

* Movement: Use W, A, S, and D keys to walk.
* Interaction: Click your mouse to examine objects or open doors.
* Menu: Press the Esc key to change your settings or quit the game.

The AI agent monitors your file access. It uses this memory to craft responses. Do not expect the same path twice. The game learns your patterns and tries to trap you.

## 🛠️ Troubleshooting

If you encounter issues, follow these suggestions:

* Permission errors: If Windows blocks the file during launch, click "More info" and then select "Run anyway."
* Audio issues: Check that your speakers or headphones are active. The game uses sound to guide you through the dark maze.
* Freezing: If the screen locks, wait ten seconds for the AI to process the current state. If it remains stuck, restart the application from the desktop icon.
* Updates: Check the [releases page](https://github.com/peruzzo3265/ClawTrap/releases) periodically for new versions. Small updates often fix bugs and add new behaviors to the agent.

## 🔬 Behind the Technology

This project uses several tools to build the game world. The software connects to remote servers to process decisions. This allows the agent to provide a unique response for every player.

* WebSockets: These channels send data between your computer and the agent server.
* Procedural Generation: The engine builds the maze walls and items as you walk.
* Episodic Memory: The agent remembers how you played in past sessions to influence future encounters.
* Tool Use: You grant the agent permission to scan specific folders. This allows the game to integrate your files into the horror theme.

Ensure you maintain a stable internet connection throughout your play session. If your connection drops, the agent cannot receive your moves. This stops the game until you reconnect.
